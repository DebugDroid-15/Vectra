# Changelog

All notable changes to Vectra will be documented in this file.

## [0.1.0] - 2026-09-14 — Initial Public Alpha

### Added
- Phase 1 Baseline Documentation (`PRODUCT_STATUS.md`, `ARCHITECTURE.md`, `COMPATIBILITY.md`, etc.).
- Multi-dock PySide6 layout shell with extreme left Current Folder, center Script Editor, right top Figure Window, right bottom Workspace Inspector, and full-width bottom Command Window.
- Universal Matrix & ECE Toolboxes (SS, DSP, Communications, Control, Symbolic).
- Diagnostic Logger & Crash Handler dialog.
- Universal Python auto-scanner and Conda PATH sanitizer in `Vectra.bat`.
